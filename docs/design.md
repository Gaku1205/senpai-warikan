# デザイン仕様

画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## このサービスらしさ
- 考え：この画面では、先輩・後輩の傾斜が、金色の「坂」（段ごとに高さの違う柱の並び）になる。段を上げ下げすると金額が決まり、均等の点線から上にはみ出た分と足りない分が、そのまま坂で動いたお金になる。
- しるし（どの画面にも必ず出す物）：
  1. 墨 #141414 の面の上の、生ビールの金 #F2B400 の柱（上に泡色 #FFF8E1 の帯）。人と金額は必ずこの柱で見せる
  2. 3段の坂の印（`src/components/Mark.tsx`。いちばん上の段だけ金）と「先輩割り勘」の名前を、上の墨の帯に
  3. 坂の急さは、言葉だけでなく5本の柱の形（`SlopeGlyph`。計算と同じ倍率から描く）で見せる。墨の上では、選んだ物だけ金の塗り、ほかは線だけ
- 埋める物：大きい文字は合計の金額（PC 56px・スマホ 44px・太字）、坂の柱の上の1人ずつの金額、柱の下の均等との差、坂で動いた額（金）。色の面は、お会計と坂の幅いっぱいの墨の面（最初の画面のほぼ全部）、LINEの文面の幅いっぱいの墨の面、下の「よく使う坂」の金の帯。本物の素材は写真ではなく、本物らしい会の中身（名前・立場・伝票の合計・期限）
- 新しい画面・部品を足すとき：まず「坂のどこに出るか」を決める。人や金額の一覧は柱か、柱と同じ比の金の棒で見せる。均等割りとの差は、別の欄にせず柱に重ねる。新しい欄は、墨の面・地の色・金の帯のどれか1つに置き、続く欄と同じ地にしない。使わない物：白い角丸カードの並び、色つきの丸に入れたアイコン、絵文字、見出しの上の小さいラベル、番号つきの3列、グラデーション、影

| 人数の欄（墨の面の中・合計の下） | 立場ごとの人数を − 数 ＋ で入れるだけで、下の坂の柱が増減する。名前は後から | 立場ごとの数 | 一覧 |

## 参考にした実例
- ventusky.com：開いた最初の画面が道具そのもので、データが画面の大半の面を持つ → 坂を最初の画面の主役の面に
- typescale.com：入れるとすぐ横の大きい結果がその場で変わる → 合計と坂の急さを、坂と同じ墨の面の上の段に
- cron.com：巨大な文字と小さい本文の大きさの差 → 合計の金額を大きく
- torikizoku.co.jp：飲み会の世界の色を面で使い切る → 墨と金（赤は使わない）
- walica.jp・splitwise.com（反面教師）：割り勘の道具なのに宣伝の見出しと挿絵から始まる → しない

## 文字
- 書体：英数字 Geist（400・500・700）、和文 Zen Kaku Gothic New（400・700・900）。`next/font/google` で読み込み、`font-family: Geist, Zen Kaku Gothic New`。数字は全部 `tabular-nums`（等幅書体は使わない）
- 大きさ：合計 56px/700（スマホ 44px）／坂で動いた額 48px/700 金（スマホ 32px）／LINEに貼る文面・よく使う坂の見出し 40px/900（スマホ 30px）／柱の金額 24px/700（柱が細いときは柱の幅に合わせて縮む。スマホ 17px）／文面 20px、題 24px/700、金額 24px/700 金（スマホ 17px・19px・20px）／会の決まりの1行 22px/700（スマホ 18px）／柱の下の均等との差 20px/700（スマホでは出さない）／お会計・坂の急さのラベル 15px/700／本文 15〜16px／ラベル 14px／柱の立場 13px／目盛り 12px
- 行間：本文 1.6、文面 1.8、見出し 1.15〜1.3
- 文言は日本語。見出しは何の欄か分かる名詞（お会計・坂の急さ・坂で先輩が多めに出した分・LINEに貼る文面・よく使う坂）。最初に入っている例の会のままなら、お会計の横に「例の会。伝票の金額に書き換えてください」、会の決まりの頭に「例：」を出す（書き換えると消える）

## グリッドと余白
- PC：中身の幅 1240px（左右 32px）。お会計と坂は幅いっぱいの1枚の墨の面：上の段に 合計｜坂の急さ｜坂で動いた額（右寄せ）、下に柱（高さ 640px、うち名前と差の段 104px）。その下に会の決まりの1行。LINEの文面は画面の端までの墨の面で、中は 左 380px（見出しとボタン）＋間 32px＋右（文面）。欄の間 56px
- 1100px 以下：上の段は 合計｜坂の急さ の下に坂で動いた額。文面の面は1列に積む
- スマホ（720px 以下）：左右 16px。お会計と坂・文面は画面の端まで広げる。上の帯は 48px。お会計と坂の面の下は 16px だけ。下に貼り付くコピーの帯（高さ約 76px）が最後の行を隠さないよう、ページの最後（下の帯）の下に `calc(76px + env(safe-area-inset-bottom))` の余白

## 部品
- 角：面 8px、入力・ボタン 6px。影は使わない
- 入力欄：高さ 44px、縁 1px #CFCFC9、白
- 合計：下に 4px の墨の線（入力中は金）。数字の幅に合わせて「円」がすぐ後ろに付く
- 人数の欄：合計の入力の下（墨の面の上、箱なし）。見出し「人数」15px/700 墨の上の灰（#B9B9B2）と、横に小さく「計 8人」14px 墨の上の灰。その下に立場ごとの5行（上司・先輩・同期・後輩・新人の順）。1行は 立場名（15px/700・幅 3em）｜− ボタン｜数（20px/700・幅 2ch・中央・`tabular-nums`）｜＋ ボタン。ボタンは編集の列の `ed-btn` と同じ（44×44px・角 6px・墨の上の入力 #262624・縁 #3A3A37・白い記号）。行の間 4px。押せないとき（0人・上限）は不透明度 0.35。数が1以上の立場は、数を金（#F2B400）にする。新しい色は足さない。スマホでも同じ並び（幅いっぱいにはせず左寄せ）
- 名前が空の人の仮の名前：柱の名前・編集の入力欄の placeholder・幹事の選択肢に「先輩1」のように出す。柱の名前の所は墨の上の灰（#B9B9B2）、太さは名前と同じ
- 文面の「先輩 2人 各 6,200円」の行：1人1行と同じ形（左に「先輩 2人」、金額は金の太字右揃え、棒は金額の比）。「各」は金額の前に付く文字で、金額の数字に含めない
- 「（端数調整）」：端数を持つ人の金額の行の後ろに足す（文面のテキストにも全角かっこで入る）。画面では金額の下に 12px・太さ 400・墨の上の灰（#B9B9B2）で小さく。棒・金額の位置は変えない。新しい色は足さない
- 坂の急さ：墨の面の上に、箱なしで4つ並び。柱の形 60×40px＋名前。選んだ物は金の塗りの形と金の文字、下に 3px の金の線。ほかは墨の上の灰の線だけの形
- 坂の柱：上に 8px の泡の帯、中の左上に金額。選んだ柱は内側に 3px の白い線と、名前の上に白い線。主役は高さ 44px の点線の枠に「0円」。目盛りは上限と「均等」の点線（2px・白、左に「均等」と金額）だけ。均等より少ない人は、柱の上から点線までを 2px の灰の枠（上と左右だけ）で描く。柱の下の名前・立場の下に、均等との差「+3,614」（金）・「−3,086」（白）を 20px/700。主役には出さない
- つかんでいる間の柱：選んだ柱と同じ見た目（内側 3px の白い線・名前の上の白い線）のまま、カーソルが `grabbing` になるだけ。影・新しい色は使わない。主役の柱はつかめず、見た目も変わらない
- 集金の済（柱の立場の行）：集金済みの人は立場の行の最後に「・済」を文字で足す（13px のまま）。金の柱の上の立場の行は今の色、新しい色・印・アイコンは足さない。柱の高さ・金額は変えない
- 集金済みのチェック：編集の列の、主役のチェックと同じ形（20px のチェック＋15px の文字「集金済み」）。主役には出さない
- 全員／まだの人だけの切り替え：文面の欄の左、見出しの説明とボタンの間。`seg` の形（角 6px・高さ 38px・15px）を墨の面の上に置く。地は墨の上の入力 #262624（縁 1px #3A3A37）、選んだ方は金の地に #3A2A00 の太字、選ばれていない方は墨の上の灰 #B9B9B2。0人のとき文面は「全員の集金が済みました。」の1行（題・合計の行・棒は出さない）
- スマホの坂：1人1行（左に名前と立場 76px、右に横向きの柱。いちばん高い人が幅いっぱい）。均等に足りない分は、柱の右から均等の位置までの枠
- 編集の列：名前・▼ 立場 ▲（44px）・主役（0円）・外す・＋1人足す
- ボタン：コピーは金の地に墨（高さ 64px・幅 260px 以上・20px/700、スマホ 56px）。「LINEを開いて送る」は 2px の #4A4A46 の枠に白い文字（高さ 56px）。スマホでは文面の欄に着くまで、画面の下に墨の帯と金のボタン「LINEに貼る文面をコピー」
- 文面：墨の面に直接、左に 6px の金の線（スマホ 4px）。題は白、合計と期限・端数は墨の上の灰。1人1行は「名前さん｜金額（右揃え・金）｜柱と同じ比の金の棒（高さ 14px・最大 420px）」。主役は棒の代わりに「（今日の主役）」
- 会の決まり：地の上の 22px/700 の1行。押せる所は 3px の金の下線、押すと金の地になり、下に入力（会の名前／丸めの切り替え／端数の切り替え／期限と幹事）と墨の「決める」ボタンが開く。開いていないときは下に「下線の所を押すと変えられます」14px 灰
- よく使う坂：金の帯の上の一覧。上に 2px の墨の線、小さい坂の形 64×40px、名前 20px/900

## 動き
- 柱・足りない分の枠・文面の金の棒の高さ・幅が 240ms で変わるだけ。入ってくる動きは無い
- つかんで動かして段が変わったときも、柱は同じ 240ms で変わるだけ（指に追いかける別の動きは足さない）
- `prefers-reduced-motion` では止める
- フォーカスは 3px の金の線

## 写真
- 使わない（道具の画面）。本物らしい会の中身で埋める。例の中身は `src/lib/sample.ts`
