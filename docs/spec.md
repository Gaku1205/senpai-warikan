# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

飲み会の割り勘を先輩・後輩の傾斜つきで1分で決めて、そのままLINEに貼れる文面にしてくれるWebアプリ（元のメモ：飲み会の割り勘を、先輩・後輩の傾斜つきで1分で決めて、LINEに貼れる文面にするWebアプリ）

## 前提

- 使う人・使う場面（デザイン担当の分析。推定を含む）：
  - 使う人：会社の課・部活・サークルの飲み会の幹事（たいてい若手）。先輩・上司が多めに払う「傾斜」をつけたい
  - 使う場面：会計の直後、店の前や2次会への移動中に、スマホで合計を入れて坂を決め、そのまま LINE のグループに文面を貼る
  - 1回1分。登録もログインも無い
- 技術：Next.js（App Router）＋TypeScript、テストはVitest

## 画面

### 割り勘の計算（`src/lib/split.ts`・`src/lib/message.ts`）

- 重み ＝ 坂の比 ^（立場 − 3）。坂の比は 均等 1／ゆるい 1.15／ふつう 1.3／急 1.5。払う人（主役でない人）の重みの合計で合計を割り、1人分は `合計 × 重み ÷ 重みの合計`
- 1人分は丸めの単位（100/500/1000）でいちばん近い値に丸める（`Math.round`。切り上げ・切り捨てではない）
- 丸めて出た端数（合計 − 丸めた額の合計）は、1人が持って金額に足し引きする。合計は1円もずれない
- 端数を持つ人：「幹事」なら幹事、「いちばん上」なら坂のいちばん上の払う人。「幹事」を選んでいても、幹事が主役（払わない人）なら、いちばん上の人が持つ（切り替えは「端数は幹事」のまま。文面の端数の行は実際に持つ人の名前を出す）
- 主役は0円。「全員」の文面は 1行目 `【会の名前】お会計のお知らせ`（会の名前が空なら「飲み会」）、2行目 `合計 X円（N人）`（N は主役を含む全員の数）
- よく使う坂：新歓は立場1の人を全員主役にする／送別会は主役をそのまま／部の打ち上げ・同期会は主役を全部外す
- 合計の入力は8桁まで。「LINEを開いて送る」は `https://line.me/R/share?text=（文面）` を開く

### 続きから使える（入れた会を端末に残す）

- 残す先は、この端末のブラウザ（`localStorage`、キー `senpai-warikan:v1`）だけ。サーバーには送らない。1つの会（最後に入れた会）だけを上書きして残す
- 残す中身：会の名前・合計（数値）・メンバー（id・名前・立場・主役）・坂の急さ・丸め・幹事・端数を持つ人・期限・選んでいるメンバー。開いている欄（会の決まりの編集中など）は残さない
- 残す時：読み込みが終わったあと、入力が変わるたびに保存する。読み込む前に例の会で上書きしない
- 読む時：最初の描画はサーバーと同じ例の会。そのあと（`useEffect`）で、残した中身があれば画面に反映する
- 残した中身が読めないとき（JSONが壊れている・形が違う・立場が1〜5でない・丸めが100/500/1000でない・坂の名前が無い・メンバーが0人または20人超・幹事や選択中のメンバーがメンバーにいない など）は捨てて、例の会のまま開く。`localStorage` が使えなくても落ちない（残せないだけ）
- 「例の会。伝票の金額に書き換えてください」「例：」は、会の名前・合計・メンバーが最初の例の会と同じ中身のときだけ出す（読み込み後も同じ判定）。書き換えて再読み込みしたら出ない
- 「新しく足した人」の id（`new-N`）は、読み込んだメンバーの id とぶつからないように決め直す

### 坂の柱をつかんで段を変える

- 対象：坂の柱（`SlopeChart` の `step`）。ポインター操作（マウス・タッチ・ペン）で、柱を押したまま動かすと、その人の立場の段（`Level` 1〜5）が変わる。ライブラリは使わず Pointer Events で書く
- 動かす向き：段が上がる向きが正。PC（柱が縦）は上に動かすと段が上がり、下に動かすと下がる。スマホ（720px 以下。柱が横向きの棒）は右に動かすと上がり、左で下がる（長さ＝払う額の向き）
- 1段ぶんの距離：柱の高さ（スマホは棒の置き場の幅）を5で割った長さ。24px 未満にはしない。つかんだ位置から1段ぶん動くごとに1段切り替わり、5より上・1より下にはならない（`src/lib/drag.ts` の `levelFromDrag`）
- 6px 動くまでは「押しただけ」。動いたら、その柱を選んだ状態（`is-sel`）にし、動かした結果は ▲▼ と同じ状態更新に流す。金額・均等との差・LINE の文面は `computeSplit` でその場で再計算される（計算は変えない）
- 動かさずに離したときは、今までどおり押して選ぶだけ。動かして離したときは、続けて選び直す押下は起きない
- 主役（`guest`）の柱は段の対象外。動かせず、押して選ぶだけ
- 縦スクロールを邪魔しない：つかむ動きは柱の上だけで受ける（PC は `touch-action: pan-x`、スマホは `pan-y`）。キーボード操作（編集の列の ▲▼）と柱の `aria-label` は今までどおり

### 集金の済んだ人に印をつけ、まだの人だけの文面を作る

- 人ごとに集金済みかどうか（`Member.paid`）を持つ。「済／まだ」の2択で、最初は全員まだ。端末にも残さない（リロードで消える。読み込んだ会は全員まだ）。部分払いは扱わない
- 付け外し：編集の列の「集金済み」のチェック（主役のチェックの隣）。主役（0円）には出さない。主役にした人の `paid` は文面・集計では使わない
- 坂の柱：集金済みの人の柱の「立場」の行は「立場・済」（幹事なら「立場・幹事・済」）。柱の高さ・金額・均等との差は変えない。`aria-label` にも「集金済み」を足す
- 文面の切り替え：LINEの文面の欄の左に「全員／まだの人だけ」の切り替え。初期値は「全員」。リロードで「全員」に戻る
- 「全員」の文面は今までと1文字も変えない
- 「まだの人だけ」の文面（`buildLineMessage` の `only: "unpaid"`）：
  - 1行目 `【会の名前】集金のお願い`（会の名前が空なら「飲み会」）
  - 2行目 `まだの方 N人・合計 〇〇円`（N と合計は、まだの人の人数と金額の合計。主役と集金済みは入れない）
  - 空行のあと、まだの人を坂の上から順に `名前さん　金額円` で1人1行
  - 空行のあと、期限・幹事の行と端数の行は「全員」と同じ形。端数の行は、端数を持つ人がまだの人に入っているときだけ出す
  - まだの人が0人のときは「全員の集金が済みました。」の1行だけ
- 切り替えに合わせて、文面・コピー・「LINEを開いて送る」・スマホの下のコピーの帯が同じ文面になる

### 人数だけで決める（立場ごとの人数を＋−で入れる）

- 場所：お会計の合計の入力のすぐ下に「人数」の欄。立場（`LEVEL_NAMES` の5つ。上司・先輩・同期・後輩・新人）ごとに1行、`− 数 ＋`。0〜20人。メンバー全体は1〜20人（合計1人のときは − を押せず、合計20人のときは ＋ を押せない）。合計の人数を欄の見出しの横に出す
- 名前は入れなくてよい。人数だけで、坂・金額・LINEの文面が出る。名前は後から、坂の柱を選んで編集の列で入れられる
- 人数の数え方：その立場のメンバーの数。主役（0円）も立場の人数に入る
- 増やす：その立場の人を末尾に足す。名前は空、主役ではない。名前が空の人は、画面では立場と番号（`上司1`・`先輩2`。同じ立場のメンバーを一覧の順に数えた番号）の仮の名前で見せる。仮の名前は入力欄の placeholder 扱いで、名前そのものではない
- 減らす：その立場の中で、名前が空の人の後ろから消す。名前が空の人がいなければ、名前の入った人を後ろから消す。主役は最後（主役でない人が残っているあいだは消えない）
- 一覧の編集（立場の ▲▼・柱をつかむ・足す・外す）で人数が変わったら、人数の欄の数も合わせて変わる。数はメンバーから数えるだけで、欄だけの別の状態は持たない（どちらから変えても同じ状態）
- 例の会：最初の例の会（名前つきの8人）の状態で人数の欄を押したら、先にメンバーの名前を全部空にしてから増減する（＝自分の会に切り替わる）。「例の会。伝票の金額に書き換えてください」「例：」の表示も消える。例の会でなければ、名前は消さない
- 幹事・選んでいる人が消えたときは、残った先頭の人にする
- LINEの文面（`buildLineMessage`）：名前が空の人（主役以外）は、同じ立場で同じ金額の人をまとめて `先輩 2人 各 6,200円` の1行にする（1人でも同じ形）。名前の入った人は今までどおり `名前さん　金額円`。順番は坂の上から（まとめた行は、その立場で最初に出る位置）。人数・合計は変えない。「まだの人だけ」の文面も同じまとめ方。名前が空の主役は `先輩1さん　0円（今日の主役）`
- 端末に残す中身（`senpai-warikan:v1`）には、名前が空の人もそのまま入る。読み込みの検証で、名前が空を弾かない
- 純粋関数は `src/lib/headcount.ts`（人数の数え方・増減・仮の名前・例の会から自分の会への切り替え）

### 文面の呼び方と端数の行

- 文面の中の人の名前は全部 `〇〇さん`。期限の行も `…までに、渡辺さんへお願いします。`（幹事の名前が空なら「幹事さん」。名前がもう「さん」で終わっていれば足さない）
- 端数の行（端数があるときだけ）：`※ 100円単位にそろえた端数（50円）は、渡辺さんの分で調整しています`。丸めの単位（`MessageInput.unit`）と端数の絶対値と、端数を持つ人を書く。多めでも少なめでも同じ形（向きは書かない）
- 端数を持つ人の金額の行の後ろに全角かっこで `（端数調整）` を足す（`渡辺さん　3,650円（端数調整）`、まとめた行も同じ）。金額の数字には含めない
- スマホの固定のコピーの帯が行を隠さないよう、ページの最後（`.foot`）に帯の高さぶん＋安全領域の余白を入れる。お会計と坂の面の下に大きな空きは作らない
