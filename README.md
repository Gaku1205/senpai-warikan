# senpai-warikan

飲み会の割り勘を先輩・後輩の傾斜つきで1分で決めて、そのままLINEに貼れる文面にしてくれるWebアプリ

- 仕様：[docs/spec.md](docs/spec.md)
- 見た目：[docs/design.md](docs/design.md)

[ai-dev-template](https://github.com/Gaku1205/ai-dev-template) の工場で、1行のメモ（飲み会の割り勘を、先輩・後輩の傾斜つきで1分で決めて、LINEに貼れる文面にするWebアプリ）から作ったサービスです。Issue を書くと、AI が清書・実装・レビュー・マージまで進めます（[docs/pipeline.md](docs/pipeline.md)）。
